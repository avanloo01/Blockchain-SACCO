# Website Next.js App

Next.js app for SACCO signup and transparency dashboards, deployed on Vercel.

Planned responsibilities:

- Public onboarding and trust pages.
- Member signup and light verification flow.
- Crossmint-hosted contribution checkout linked from Telegram `/contribute` intents.
- Wallet connect support (non-custodial + embedded path).
- Public aggregate transparency views and private member dashboard.

Required runtime/build env for checkout:

- `NEXT_PUBLIC_CROSSMINT_CLIENT_API_KEY`

See architecture details in `../docs/architecture/website-architecture.md`.
